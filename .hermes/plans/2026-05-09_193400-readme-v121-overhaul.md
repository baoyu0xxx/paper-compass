### paper-compass 的核心差异化定位

> **唯一一个将 RAG 检索和 LLM wiki 知识管理结合起来、并通过 MCP 标准协议专为 AI Agent 设计的个人学术知识库系统。**

三个关键词：**Agent-first**（MCP 协议）、**双引擎**（RAG + wiki）、**继承最优**（RAG-Assistant-for-Zotero 核心模块 + llm-wiki 方法论）。

### 2. 新增「为什么是 paper-compass」章节

放在「项目简介」之前或作为其一部分。内容包括：

- **创建动机**：Zotero 用户的真实痛点——元数据可搜、正文难找。RAG-Assistant-for-Zotero 解决了"对话式问答"，llm-wiki 解决了"知识编译"，但没有一个工具同时做到：**让 Agent 既能精确检索原文段落，又能浏览 LLM 编译的结构化知识，还能通过标准协议无缝接入任何 Agent 框架**。
- **对比表**：vs llm-wiki-skill、vs RAG-Assistant-for-Zotero（6-8 个维度）
- **继承与创新**：PDF 提取、Zotero SQLite 读取、嵌入、向量存储继承自 RAG-Assistant-for-Zotero；LLM wiki 方法论借鉴 Karpathy llm-wiki；创新点在于 MCP 协议集成、增量索引、中文分词检索、CLI 配置等
