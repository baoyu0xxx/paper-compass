# ⚠️ MIGRATION NOTICE (v1.2.1)

This file has been moved to `prompts/disciplines/economics/wiki_overview.md` as part of the v1.2.1 prompt customization feature.

**What changed:** paper-compass now supports discipline-specific prompt presets and a general default. The economics-specific prompts are now a discipline preset.

**To continue using economics prompts:**

Option 1: Run `paper-compass init` and select "Economics" in the prompt step.
Option 2: Add `WIKI_PROMPT=economics` to your `.env` file.

**For new users:** The default prompt set (`prompts/wiki_overview.md`) is now discipline-agnostic — suitable for any field.

See README.md for details on the prompt customization system.
